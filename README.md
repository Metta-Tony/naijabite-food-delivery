# NaijaBite Food Delivery

NaijaBite is a React food delivery storefront for ordering Nigerian meals across southeastern cities.

## Run Locally

**Prerequisites:** Node.js


1. Install dependencies: `npm install`
2. Start the local development server: `npm run dev`
3. Open `http://localhost:3000`

## GitHub Pages

Push the `main` branch to GitHub, then enable **GitHub Actions** as the Pages source in the repository settings. The site will be available at `https://metta-tony.github.io/naijabite-food-delivery/` after the workflow completes.

## Production build

Run `npm run build` to create the production bundle.
